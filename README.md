### 1. 🍲 拼音料理屋（沪教版一年级语文拼音与识字 · 10 关 · 436 字词）
- **🧭 前鼻音 L6 / 后鼻音 L10 科学分流 + 自成音节 `er`**：将前后鼻音拆分为「第 6 关 · 前鼻音（`an en in un ün`）」与「第 10 关 · 后鼻音强化（`ang eng ing ong`）」，并在第 8 关纳入自成音节 `er`（`儿 / 耳 / 二`），全库 436 个组词全部采用一年级生活化、正面童趣短词。
- **🧂 四声调料瓶两步减负法**：告别满屏带调韵母眼花缭乱！先选**无调韵母母体**（如 `ao`、`ang`），再撒上 **4 个四声调料瓶（一声平、二声扬、三声拐弯、四声降）**，配合无冲突单韵母四声标音与一年级适龄语速（`slow: 0.39` / `normal: 0.45`），精准攻克二声/三声混淆痛点。
- **🔊 真拼读连读演示**：答对后自动播放「声母 →（介音）→ 韵母 → 完整音节+组词」连读示范，槽位同步高亮放大（支持三拼慢速拼读与全明星挑战）。
- **🕶️ `j / q / x` 遇到 `ü` 去两点魔法横幅**：第 4 关起预置并动态提示「小熊摘墨镜」口诀；macOS 键盘输入同步兼容 `v → u / ue / un` 与 `z / c / s + h` 组合键。
- **🛎️ 神秘锅盖盲听模式**：先听读音再选卡，答对瞬间锅盖揭开、热气腾腾上菜。

## 🚀 在 Mac 与 iPad 上如何运行与迁移存档？

### 方式一：在 Mac 上一键编译运行原生应用
1. 在 Finder 中打开本项目目录，直接双击 **`满满的奇妙料理城.app`** 即可启动！
2. 如果修改了代码或需要重新打包，在终端执行一键打包脚本：
   ```bash
   ./build-mac-app.sh
   open "满满的奇妙料理城.app"
   ```

### 方式二：在 iPad 上使用 Swift Playgrounds 导入运行
1. 将项目中的 **`PinyinKitchen.swiftpm`** 文件夹（或桌面打包好的 `PinyinKitchen.swiftpm.zip` 解压后）通过 **AirDrop（隔空投送）** 或 **iCloud 云盘** 发送到 iPad。
2. 在 iPad 上打开 **Swift Playgrounds**，点击打开 `PinyinKitchen.swiftpm`，再点右上角 **▶️ 运行** 按钮即可全屏畅玩！

### 方式三：iPad / Mac 跨端存档备份与版本迁移
1. 应用每答一题都会自动保存至本地多重存储路径（`ApplicationSupport` / `Documents` / `UserDefaults`），重启或覆盖安装不丢失进度。
2. 如需**跨设备同步或重装迁移**：点击顶部 **「💾 备份/导入」** 或进入 **「🏆 成长档案」** 顶部的备份卡片：
   - **剪贴板快传**：点 **「📋 一键复制存档码」** 粘贴到备忘录/微信，在新设备点 **「📌 一键从剪贴板恢复」** 即可自动合并。
   - **文件导出**：点 **「📤 导出到『文件』/ 微信」** 通过系统 `ShareLink` 导出 `满满的奇妙料理城_存档备份.json`（若无备份文件可先点 **「🔄 刷新 / 重新生成备份文件」**）。
   - **智能防膨胀合并**：导入时采用去重与取最大值策略，错题次数与历史记录不会重复翻倍；从旧版本升级时，历史蝴蝶数据会自动静默折算迁入公主衣橱。
