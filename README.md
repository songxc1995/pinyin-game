## 🌟 三大沪教版一年级主题场馆

### 1. 🍲 拼音料理屋（沪教版一年级语文拼音与识字 · 9大关卡 · 443字词）
- **🧂 四声调料瓶两步减负法**：告别满屏带调韵母眼花缭乱！先选**无调韵母母体**（如 `ao`、`ang`），再撒上 **4 个四声调料瓶（一声平、二声扬、三声拐弯、四声降）**，精准攻克二声/三声混淆痛点。
- **🔊 真拼读连读演示**：答对后自动播放「声母 →（介音）→ 韵母 → 完整音节+组词」连读示范，槽位同步高亮放大。
- **🕶️ `j / q / x` 遇到 `ü` 去两点魔法横幅**：拼出 `ju / qu / xu / juan` 等音节时自动弹出「小熊摘墨镜」口诀。

## 🚀 在 Mac 与 iPad 上如何运行？

### 方式一：在 Mac 上直接双击运行原生应用
项目根目录已为你打包好 macOS 原生应用 **`满满的奇妙料理城.app`**：
1. 在 Finder 中打开本项目目录，直接双击 **`满满的奇妙料理城.app`** 即可启动！
2. 如果修改了代码，只需在终端运行一键打包脚本：
   ```bash
   ./build-mac-app.sh
   open "满满的奇妙料理城.app"
   ```

### 方式二：在 iPad 上运行（Swift Playgrounds 或 Xcode）
1. 将项目中的 **`PinyinKitchen.swiftpm`** 文件夹通过 **AirDrop** 或 **iCloud Drive** 发送到 iPad。
2. 在 iPad 上使用免费的 **Swift Playgrounds** 打开 `PinyinKitchen.swiftpm`，点击右上角 ▶️ 即可全屏畅玩！
